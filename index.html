Windows / macOS 使用條件與連線疑難
      
請使用桌面版 Chrome 或 Edge，並從 HTTPS 網址開啟。Safari、Firefox 不支援此頁所需的 WebUSB。

      
macOS 通常不需要安裝驅動。請先結束 CubeProgrammer、CubeIDE 偵錯或其他正在使用 ST-LINK 的程式。

      
Windows 11 必須讓 ST-LINK 的 USB 介面使用 WinUSB。如果顯示無法開啟或取得介面，可能需要一次性驅動設定；純網頁無法自行安裝驅動，也無法保證所有 V2 相容棒都免安裝。

      
此版本支援 ST-LINK/V2（0483:3748）及 V2-1（0483:374B），探針需具備 API v2 與 SWD 調速功能（J22 以上）。不支援 V1、V3、J-Link、解除讀保護或修改 Option Bytes。若既有韌體關閉 SWD 或進入低功耗而無法連線，需用原廠工具的 under-reset 方式救援。

      
識別碼只能確認 G03x/G04x 家族與容量，無法辨識封裝或完整料號；請確認實際晶片標示為 STM32G031G8U6。
